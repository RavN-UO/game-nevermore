# NEVERMORE 🖤🪶

A one-thumb gothic arcade game. **Hold to dive, release to rise** — thread a
raven through an endless gothic abyss, grazing spires for near-miss bonuses,
collecting souls to build a combo multiplier, and chasing "one more run".

Built with **Phaser 3 + TypeScript + Vite**, shipped as an installable **PWA**,
and ready to wrap with **Capacitor** for iOS. Every visual is generated by code
and every sound is synthesised at runtime with **Tone.js** — there are no image
or audio files in this repo.

---

## Quick start

```bash
npm install
npm run dev        # dev server, bound to 0.0.0.0
```

Open the printed `http://localhost:5173`, or, **to play on your iPhone**, open
`http://<your-computer-LAN-IP>:5173` in Safari on the same Wi-Fi (e.g.
`http://192.168.1.42:5173`). Then **Share → Add to Home Screen** to install it
full-screen as a PWA (notch-aware, offline-capable).

```bash
npm run build      # typecheck + production build into dist/
npm run preview    # serve the production build (also --host)
```

> First-run note: the game shows a **TAP TO BEGIN** screen. That tap is required
> to unlock audio on iOS (Web Audio can't start without a user gesture).

## How it plays

- **Control**: press & hold anywhere = **dive** (the raven tips down and
  accelerates); release = **lift/glide** (it naturally rises). Velocity + inertia,
  not snap positions — weighty but responsive. One touch into a spire = death.
- **Combo**: collect floating **souls** to raise a multiplier (up to ×12). It
  decays if you go too long without one. The multiplier scales **score and
  Plumes**.
- **Near-miss**: skim a spire without hitting it for bonus points, a slice of
  **slow-mo**, a particle ring and haptic feedback — the risk/reward core.
- **Meta**: earn **Plumes** to unlock cosmetic **skins** and permanent
  **upgrades** (soul magnet, plume multiplier, start shields, a revive token,
  head start). Level up an account **reward track**, complete **achievements**,
  keep a **daily streak**, and chase the rotating **daily challenge**.
- **Ranks**: local leaderboard always; global leaderboard via Supabase when
  configured.

All tuning lives in **`src/config/balance.ts`** — change feel, difficulty and
economy without touching logic.

```
  config/   balance.ts    ALL gameplay tuning      theme.ts   palette + fonts
  gfx/      TextureFactory.ts   procedural textures, generated once at boot

            ProgressionSystem  Leaderboard  ObjectPool
  data/     skins  upgrades  achievements  dailyChallenges   (pure data)

  ui/       Widgets.ts    reusable buttons / panels / sliders / badges

```

### Performance (the non-negotiable: 60 fps)

- All movement is **delta-time** based, so feel is identical at 60 Hz or 120 Hz
  ProMotion.
- **Object pooling** for obstacles and souls — nothing is instantiated or
  destroyed mid-run (no GC stutter).
- Visuals are **baked textures** reused as sprites / tile-sprites / particle
  textures — never redrawn per frame. Parallax uses tile-sprites.

## Online leaderboard (optional, Supabase free tier)

The game is fully playable offline; global ranks are an optional add-on.

1. Create a Supabase project and run:

   ```sql
   create table scores (
     id bigint generated always as identity primary key,
     name text not null,
     score int not null,
     distance int not null default 0,
     created_at timestamptz default now()
   );
   alter table scores enable row level security;
   create policy "anon insert" on scores for insert to anon with check (true);
   create policy "anon read"   on scores for select to anon using (true);
   ```

2. Copy `.env.example` to `.env` and set `VITE_SUPABASE_URL` and
   `VITE_SUPABASE_ANON_KEY`. Rebuild. The GLOBAL tab now works; without the env
   vars it shows a friendly "offline" message.

The leaderboard is behind a `LeaderboardService` interface, so a future Game
Center backend (via Capacitor) can drop in without touching the scenes.

## iOS native build (Capacitor — optional, phase 6)

You do **not** need this to test on your iPhone (use the PWA above). For
TestFlight / App Store:

```bash
npm install @capacitor/core @capacitor/cli @capacitor/haptics
npx cap add ios
npm run build && npx cap sync
npx cap open ios     # opens Xcode
```

`capacitor.config.ts` is already provided. `HapticsManager` automatically uses
the **native Capacitor Haptics** plugin when running in the app, and falls back
to `navigator.vibrate` in the browser (note: iOS Safari does not support
`vibrate`, so PWA haptics are Android-only — native build fixes this on iOS).

Publishing to the App Store requires the Apple Developer Program (99 €/yr).

## Tooling scripts

- `npm run icons` — regenerate PWA icons (pure-JS PNG encoder, no native deps).
- `npm run smoke` — headless Playwright smoke test: boots the game, builds the
  audio engine, walks every scene, plays a run to the reward screen, and fails
  on any console error/exception (screenshots in `.smoke/`). Requires a running
  `npm run preview` and `npx playwright install chromium` once.

## Design notes (what was kept, what was decided)

Per the brief's invitation to exercise game-design judgement, the **core
concept (gothic raven, endless abyss, dark-synth audio) was kept** — it's
atmospheric and fits the procedural-everything constraint well. Concrete
decisions made along the way:

- **Inverted buoyancy control** (release = rise, hold = dive). The default
  threat is drifting *up* into the ceiling, which makes "doing nothing"
  dangerous and gives diving real intent — more interesting than Flappy taps.
- **Custom delta-time physics** (not Arcade Physics) for full control over
  momentum, drag and tilt smoothing — the "weighty but responsive" feel.
- **Forgiving collision**: a smaller-than-sprite hitbox and a horizontally inset
  obstacle column, so deaths feel fair and near-misses feel earned.
- **A ghostly accent halo** behind the raven so the deliberately-dark default
  skin always reads against the dark sky (doubles as atmosphere).
- **Procedural adaptive music**: five Tone.js layers (pad/sub/arp/perc/lead)
  cross-fade in with the difficulty tier and the tempo creeps up — dark
  electronic/industrial, as the brief recommends for convincing fileless audio.
- **Instant restart**: the death screen *is* the restart surface — one tap
  anywhere relaunches, and a finger already held carries into the first dive.

Nothing in the original concept was discarded; these are refinements.
